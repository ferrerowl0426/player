# 计划书 — 转微信小程序（仅学生端）

> 依据：`docs/PRD.md` v1.0.5（学生侧能力以 PRD §3 权限矩阵的「游客 / 学员」两列为准）  
> 定位：Web 端继续承担**老师端 + 教导主任（管理端）**&#x5168;部职责；小程序只做学生侧的**看课入口**。  
> 原则：轻量。后端 API 几乎全复用，前端按小程序规范重写（不是移植 Next.js）。

---

## 0. 范围

### 做什么

小程序内只出现学生视角的页面：

| 页面     | 对应 PRD | 说明                                           |
| ------ | ------ | -------------------------------------------- |
| 登录     | §5.11  | 账号（手机号）+ 密码，**复用现有 users 表与登录接口**            |
| 首页     | §5.9   | 老师推送的作业视频卡片 + 老师留言；**含停用态**（"资源免费开放半年…"）     |
| 曲目库    | §5.1   | 上下两区（曲目/曲谱集）+ 搜索，滚动加载                        |
| 曲目合集详情 | §5.1   | 面包屑 + 合集头 + 收录网格 + 分页                        |
| 单曲目详情  | §5.1   | 播放器（**含清晰度切换**）+ P 列表 + 附件资料 + 关联图书馆         |
| 知识点区三页 | §5.2   | 与曲目区同构                                       |
| 图书馆    | §5.3   | 资料浏览 + 图书详情 + 下载                             |
| 我的历史作业 | §5.9   | 按 operation 聚合 + 留言；**含停用态**（"老师之前带你学到了这里…"） |

- **游客模式**：未登录可浏览曲目库/知识点区/图书馆并播放视频（与 PRD 游客列一致），无首页；在小程序内体现为"进入即浏览 + 顶部登录提示条"。
- **清晰度切换**：沿用 PRD §4.7——默认 1080p，CI 转码产物，播放器档位菜单逻辑照搬，仅 UI 按微信规范重画。

### 不做什么（小程序端）

- 老师、教导主任的全部功能（学生管理、班级管理、账号管理、**所有上传/编辑/删除**）——仍走 Web 端
- COS 分片直传（学生不上传任何东西，小程序内不存在上传代码）
- 注册、自助改密、找回密码（账号仍由教导主任在 Web 端发放）

## 1. 技术选型

| 方案                    | 结论                                                                |
| --------------------- | ----------------------------------------------------------------- |
| **Taro 4（React）✅ 推荐** | 团队已用 React 19 + Next.js，组件心智直接复用；一套代码可同时产出微信小程序与 H5（H5 可留作以后降级方案） |
| 原生小程序                 | 性能与调试体验最好，但要重学一套语法，且以后想做 H5 要再写一遍                                 |
| uni-app（Vue）          | 与现有 React 栈不符，不选                                                  |

- 状态与请求：Taro + 自封装 `request.js`（对齐现有 `lib/api.js` 的错误处理约定）
- UI 基调：**微信官方设计规范（WeUI 风格）**，750rpx 栅格；色彩令牌直接沿用 design-spec v2.0 的 CSS 变量值（--ink/--coffee/--orange 等）映射成 SCSS 变量，保持与 Web 端同一品牌观感

## 2. 前置硬条件（P0，不满足则无法上线）

1. **注册小程序**：企业主体或个人主体认证；取得 AppID/Secret（个人主体不能开通某些类目，教育类目建议用可认证的主体）
2. **域名要求**（微信服务器域名白名单三项全部强制 **HTTPS + ICP 备案**）：
   - request 合法域名：`https://api.你的域名`（后端 API）
   - downloadFile 合法域名：COS 媒体/附件下载域名（附件、图书下载走它）
   - video 组件的播放地址域名同样需在白名单内（COS 自定义域名或经 API 代理）
   - ⚠️ 开发期可在开发者工具勾选"不校验合法域名"调试，**真机体验版也需在手机上开调试模式**，正式版必须满足上述条件
3. **COS 侧配置**：
   - 视频播放：小程序 `video` 组件请求不带常规 Referer，COS 防盗链需放行 `servicewechat.com` 或改用**签名 URL**（推荐：后端发签名 URL，同时解决防盗链）
   - 附件下载：COS 文件走 `Taro.downloadFile`，同样受白名单约束
4. **CI 数据万象转码**：与小程序无关，零改动
5. **现有 Web 端不受影响**：后端新增小程序鉴权通道时保持旧 cookie 会话兼容

## 3. 登录方案（推荐 A，可选 B）

- **A（推荐，先做）**：小程序登录页输**账号（手机号）+ 密码** → 调现有 `POST /api/user-auth/login` → 后端签发 JWT（小程序无 cookie，token 放 storage，请求头 `Authorization: Bearer`）。改动最小：后端加一条"token 会话"通道即可。
- **B（可选增强，二期）**：`wx.login` 获取 openid 与账号绑定，之后一键登录。需要 users 表加 `openid` 字段 + 绑定流程页。**一期不做**。

停用账号逻辑照旧：登录放行，接口返回 `status=disabled`，前端渲染两处停用文案（逐字对照 PRD §8）。

## 4. 任务分解

### P0 立项与基础设施（约 2~~3 天动手 + 2~~4 周等待备案）

**主体定位（已确认）**：**个人主体**小程序，仅本人及自己学生使用、非经营性、无支付——免 300 元认证费；类目&#x9009;**「工具」（视频播放/内容展示）**，服务描述写"供本人学员观看自建课程内容的非经营性内部工具"；⚠️ 避开"教育-在线教育"类目（需办学许可证，个人主体办不了）；红线：小程序内不放任何收费/广告/付费导流入口。

备案分两件事（个人口径）：

1. **域名 ICP 备案（先做，前置依赖）**：API 域名在腾讯云控制台提交个人备案（身份证正反面 + 人脸核验 + 本人实名手机号 + 通讯地址精确到门牌号），腾讯云初审 1~~2 天 → 管局 3~~20 个工作日；**视频/附件直接用 COS 默认域名（`xxx.cos.<region>.myqcloud.com`，腾讯已备案），个人无需自备**
2. **小程序备案（注册后 20 个自然日内必须完成）**：微信公众平台后台（设置 → 基本设置 → 小程序备案）→ 个人主体信息（微信扫码人脸核验，本人操作）→ 服务类目 + 已备案的 API 域名 → 电子签署《非经营性互联网信息服务备案登记表》→ 微信初审 1~~3 个工作日 → **24 小时内**完成工信部短信核验（beian.miit.gov.cn）→ 管局终审约 7~~15 个工作日 → 获得备案号并在小程序"关于"页展示

其余动手项：

- [ ] 注册**个人主体**小程序，取得 AppID
- [ ] API 域名 HTTPS + 个人 ICP 备案提交（上项 1）
- [ ] 后端 `user-auth.routes.js` 增加 JWT token 会话通道（微信端无 cookie）
- [ ] COS：配置签名 URL 发放接口（`GET /api/media/sign?objectKey=`，仅返回短时效签名地址）；防盗链调整
- [ ] Docker：`docker-compose.yml` 增补确认——**后端 + Postgres + Web 前端三个服务不变**；后端容器暴露 HTTPS（由服务器 Nginx/Caddy 反代终结 TLS）

> 小程序代码本身**不经 Docker 部署**：开发与发布全部走微信开发者工具（预览 → 体验版 → 审核 → 发布）。Docker 只服务 Web 端与后端。

## 6. 风险与开放问题

1. **ICP 备案 + HTTPS 是最长的前置等待项**——若现在还没有备案域名，P0 第一天就启动。
2. **审核类目**：按个人主体 + 工具类目（视频播放/内容展示）+ 非经营性定位申报；**不要选"教育-在线教育"**（需办学许可证）。被驳回时按驳回原因调整服务描述，内容本身就是吉他教学视频，无资质类目下以"内部内容工具"口径申报
3. **附件格式**：GP/MP3/PNG 等在小程序内 `downloadFile` 后只能保存/转发，**不能在线预览**（如 GP 曲谱），预期管理好学员预期。
4. **开放问题（需用户决策，不阻塞 P0/P1）**：是否要做微信一键登录（方案 B）；tabBar 四个入口是否就是 首页/曲目库/知识点区/图书馆（"我的"入口承载历史作业与退出登录）。
