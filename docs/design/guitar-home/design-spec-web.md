# 能学慧吉他教室 · 设计规范

> 适用范围：吉他教室 Web 端全部页面（两区首页 / 课程与知识点详情 / 图书馆 / 学生与班级管理 / 学员端 / 管理创建页）
> 版本：v2.0 · 2026-09
> 基准：以「知识点区首页」（knowledge-home.html）为全站视觉基准页提炼。
> v2.0 变更摘要：页面底色改纯白 + 焦糖咖啡格纹底饰；强调橙统一为 `#ff7f00`（琥珀马克笔色废除）；阴影全面收敛为轻柔漫射（硬偏移投影废除）；卡片改为细边轻框；导航取消全局搜索按钮与顶部渐变条；新增首页组件规范（共用搜索条 / 排序下拉 / 翻页器）。
> 特例：登录页（login.html）为独立水彩明信片风格，不适用本文档背景与导航规范。

| Token | 色值 | 用途 |
|---|---|---|
| `--glass` | `rgba(255,255,255,.85)` | L1 容器盒子底色（半透白） |
| `--glass-line` | `rgba(93,67,38,.32)` | 描边/分隔通用线色 |

### 2.3 马克笔橙（半透明强调）

琥珀色 `rgba(233,178,80,…)` **全线废除**，统一换为亮橙马克笔：

| 场景 | 色值 |
|---|---|
| 荧光笔下划 / 高亮底（主） | `rgba(255,127,0,.42)` |
| 空态文字高亮 mark | `rgba(255,127,0,.46)` |
| 浸染底 / 排序章底 | `rgba(255,127,0,.12)` |

### 2.4 绿色使用纪律

绿色**只做点睛**，禁止大面积使用。仅允许出现在：
- 播放列表「正在播放」行的高亮底与文字；
- 均衡器跳动条（eq bars）；
- 前置知识点「未学习」圆点；
- 页头头像在线状态点。

### 2.5 标记紫（学生标记专用）

| Token | 色值 | 用途 |
|---|---|---|
| `--mark` | `#7b5ea7` | 学生管理页「学生标记」圆点与标记按钮 |

- **不承担危险语义**：停用 / 删除 / 校验报错继续用危险红 `#b4452e`，两者不得混用；
- 未标记 = 咖啡色空心圆点（hover 该行时浮现），已标记 = 紫色实心圆点（常驻显示）；
- 仅**教导主任**可见可操作，与 `.dean-only` 口径一致（老师视角不渲染）；
- 同为小圆点语义，绿色（在线 / 未学习）与本紫（标记）不得出现在同一位置；
- 批量出口：学生列表区头右侧「清除全部标记 · N」，无标记时不显示，点击走二次确认弹层（确认键用紫底，**不用**危险红——标记清除不是删除操作）；
- **停用学生不参与标记**：一旦停用即回到未标记状态，列表圆点与头部标记按钮均不渲染（他既不能被标记，也不占清除计数）。

## 3. 页面底色与格纹底饰（v2.0 核心）

### 3.1 页面底色

- **body 纯白 `#ffffff`**（替代旧版米黄纸底 / 木纹图 / 圆点装饰）。
- 内容全部浮在白底 + 格纹之上，层次依靠 L1/L2 两级边框阴影体系（见 §4）。

### 3.2 格纹底饰（唯一全页装饰）

```css
/* 格纹底饰：焦糖咖啡色 · 下浓上淡 · 近页头逐渐消失 */
body::after{display:none}
body::before{
  content:"";position:fixed;inset:0;pointer-events:none;z-index:-1;
  background:
    repeating-linear-gradient(90deg, rgba(122,74,38,.16) 0 1px, transparent 1px 72px),
    repeating-linear-gradient(0deg,  rgba(122,74,38,.16) 0 1px, transparent 1px 72px),
    repeating-linear-gradient(90deg, rgba(122,74,38,.06) 0 1px, transparent 1px 18px),
    repeating-linear-gradient(0deg,  rgba(122,74,38,.06) 0 1px, transparent 1px 18px);
  -webkit-mask:linear-gradient(180deg, transparent 0%, rgba(0,0,0,.12) 30%, rgba(0,0,0,.55) 62%, #000 100%);
          mask:linear-gradient(180deg, transparent 0%, rgba(0,0,0,.12) 30%, rgba(0,0,0,.55) 62%, #000 100%);
}
```

规格要点：
- 双层格：**72px 主格（.16）+ 18px 细格（.06）**，焦糖咖啡色 `rgba(122,74,38,…)`；
- 透明度用垂直 mask 控制：**底部最清晰 → 向上渐淡 → 页头处完全消失**；
- `pointer-events:none` + `z-index:-1`，纯装饰不拦截交互；
- 旧的「角落圆点半调网点」装饰**废除**。

## 7. 首页组件规范（两区首页 / 图书馆）

### 7.1 共用搜索条（页级唯一搜索入口）

- 位置：导航下方工具行（与预览视角切换同行，左侧）；
- 样式：白底 + `1.5px solid var(--coffee)` 6px 圆角，内置放大镜 icon + 输入框 + 「清除」小按钮（仅输入时显示）；
- 行为：**一条搜索框同时过滤本页两个区**（曲目+曲谱集 / 知识点集+知识点）；
- 空态两级：分区内空态（「XX中未找到与「关键词」相关的内容」）+ 两区全空的全局空态卡片（大字 mark 高亮 + 「清除搜索」按钮）；
- 搜索变化时分页重置回第 1 页。

### 7.2 区块（.zone）与区头（.zone-head）

- 区块 = L1 容器；区头：H2 标题（咖啡色，左橘竖条）+ 底部 64×3px 橘色马克笔下划 + 数量 meta + 控件；
- **排序下拉**（`.order`）：原生 `<select>`，`appearance:none` 自绘咖啡色小箭头；白底细边 4px 圆角，hover 描边变橘；
  - 选项：**按更新时间倒序（默认）/ 按更新时间正序 / 按首字母**（zh-CN 拼音序）；
  - 每区独立排序，切换后该区分页重置回第 1 页。
- 区头右侧操作按钮（`.zbtn`）：教导主任专属（新建合集/单课等），11px 字距 1.5px。

### 7.3 卡片网格与卡片

- 网格：每行 8 张 `repeat(8, minmax(0,1fr))`，矮视口 `min(17vh,12.5%)` + 两端贴边；
- 卡片 = L2 细边轻框（见 §4）；等高（`height:100%`）；封面 + 名称 + meta（更新时间）；
- **卡片不带任何状态角标**（「最近更新」标签已废除，排序语义交给排序下拉）；
- 教导主任悬停操作层：居中磨砂玻璃竖排（编辑/删除/下载/查看详情），删除需二次确认弹层。

### 7.4 翻页器（.pager）

- 白底 `var(--white)` + 顶部虚线分隔；「上一页 / 第 X 页 · 共 Y 页 / 下一页 / 跳转到 X 页」；
- **单页时也常驻显示**（共 1 页时上下页按钮为禁用态）；
- 图书馆特例：每页行数按框高自适应但封顶 2 排，网格 `align-content:center` 上下留白均等。

## 8. 详情页组件（课程 / 知识点共用模板）

### 8.1 布局骨架（一屏完成，页面级不滚动）

```
┌─ 导航 56px（flex:none）
└─ .detail（flex:1 · max-width 1440px · 居中 · padding:16px 36px 20px）
   ├─ 左列 .main  = min(calc((100vh - 354px) * 16/9), 1fr)
   └─ 右列 .side  = 300px
   列间距 36px · 垂直预留 --vres: 354px
```

- 页面级 `overflow:hidden`，滚动只发生在盒内（`.scroll`，4px 细滚动条）；
- 左列整块合并大盒（L1），内部虚线分隔：面包屑 → 标题 → 前置知识点 → 播放器 → 简介；
- 右列：播放列表 `flex:1.55` + 附件资料 `flex:1`。

### 8.2 播放器（.video）

- `aspect-ratio:16/9`；纯白实底 + 1.5px coffee 描边 + 无阴影；
- 角标「正在播放」：绿色呼吸圆点（2.4s pulse）；唱片 12s 匀速旋转；
- 悬停控制层：进度条 2px 橘色已播放；主播放钮 42px 橘底白 icon；倍速胶囊钮循环 0.5–2.0×。

### 8.3 盒子标题（.box-head）

咖啡色 H2 + 左侧 4×14px 橘竖条 + 底部橘色 64×3px 马克笔下划。

## 9. 交互与动效

| 项目 | 规范 |
|---|---|
| 缓动 | 全站统一 `cubic-bezier(.16,1,.3,1)`（`--ease`） |
| 入场 | `.rise`：上移 12px 淡入 0.7s，延迟梯度 .08s / .16s |
| hover 反馈 | 颜色过渡为主（0.25–0.3s），按钮不变换位置；卡片允许 2px 上浮 |
| 尊重系统设置 | `prefers-reduced-motion` 关闭入场/eq/呼吸动画 |
| 键盘可达 | `:focus-visible` 全局 `1.5px solid var(--ink)` 轮廓，offset 3px |
| 删除操作 | 一律二次确认弹层（L1 弹层 + 危险项红调 `#b4452e`） |

### 9.1 班级管理编辑口径

- 账号行统一使用「编辑」入口：教导主任、老师、学员均进入同一「编辑资料」弹层，不再在行内出现独立「重置密码 / 设置班级 / 转班 / 移出本班」按钮；
- 编辑资料弹层：账号只读不可更改，昵称可编辑（≤10 字且无特殊符号）；密码默认只展示已设置状态，不展示明文，只有点击「重置密码」后才出现新密码输入框（5~30 位），保存后覆盖；
- 老师编辑：仅展示所带班级，不在老师资料弹层里分配班级；一个老师可负责多个班级；
- 学员编辑：班级关系在弹层内单选，允许选择「未分班学员」虚拟班级；一个学生只能属于一个班级；
- 新建班级只填写班级名称，不填写备注，也不强制分配老师；负责老师后续在班级「编辑」中维护；
- 班级编辑：可改名，可更换负责老师；一个班级只能有一位负责老师，选择控件必须是下拉选单，不使用打钩多选列表；
- 学员删除 = 彻底删除学员数据，必须使用危险红二次确认文案明确提示不可恢复；
- 初始超级管理员不可编辑、不可删除，编辑入口不出现，删除按钮置灰不可点击；
- 入口文案统一使用「新建」：新建学员 / 新建老师 / 新建教导主任 / 新建班级，不使用「添加」或「新增」。
- 班级管理列表：正常状态不显示额外「正常」标签；停用行使用灰色底并保留「已停用」标签。
- 账号列表所有元素默认横向单行排列：头像、姓名、账号、操作按钮保持同一行；姓名宽 76px、账号宽 106px，超出使用省略号，保证各行对齐。
- 老师班级标签放在手机号下一行；人数过多时列表只在盒内滚动，**未发生滚动时最后一行保留下边缘线，发生滚动时最后一行去掉底线**，避免滚动区域底部出现截断线。
- 班级管理主体布局恢复为上排「教导主任 / 老师」两框、下排「班级 / 学员」联合框；联合框内部保持班级与学员左右分栏，不改变其功能与操作。
- 班级管理账号列表统一使用头像、姓名、账号、操作按钮的单行格式与一致行高；老师不在列表行展示所带班级；教导主任、老师、学员均提供「编辑 / 停用 / 删除」操作，学员沿用同一行格式；初始超级管理员删除按钮置灰且不可操作。页面不得出现横向滚动。
- 班级行仅提供「编辑 / 删除」；删除班级后，该班级下全部学生统一转入「未分班学员」，不删除学生账号与学习记录。
- 新建与重置密码均支持手动输入或随机生成；密码不展示、不保存明文，输入长度按 5~30 位校验。
- 学生管理页的作业留言拆分为上下均分的「练习要求」与「提交要求」两个输入框；作业视频、练习要求、提交要求按栏目独立更新，某栏当天提交为空即学生首页当天该栏目为空，不影响其他栏目；每次点击推送均新增一条作业记录，同一天允许多次布置，历史作业不覆盖；提供「上次作业」快捷键，从学生首页当前今日作业（若无则取最近历史作业）回填视频作业与两条留言，方便老师修改；最新一条未删除作业不可直接删除，必须先布置新作业后才能删除旧记录；历史作业对应显示两条独立留言，保留输入时的回车换行，单条超过 3 行时在留言区域内滚动，不撑高整条历史记录。

## 11. 禁止事项（Design Red Lines）

1. ❌ 大圆角、胶囊盒子、可爱风圆润组件；
