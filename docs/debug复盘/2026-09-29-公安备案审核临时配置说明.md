# 2026-09-29 公安备案审核临时配置说明

> 本文档记录公安备案审核期间的临时前端改动。审核完成后应按本文“恢复方式”删除这些临时内容。

## 1. 改动目的

为了便于公安备案审核人员首次访问网站时了解平台性质，并能够使用测试账号自行登录核验，本次做了两类临时调整：

1. 未登录用户首次打开网站根路径时，直接进入游客视角的曲目区。
2. 登录页底图区域显示备案审核说明、平台性质说明和审核测试账号。

## 2. 当前对外说明口径

登录页临时展示以下说明：

```txt
本站仅供吉他爱好者整理学习笔记与课程资料，无广告，不开放公共注册，无支付功能。

审核测试账号：13382800426
审核测试密码：demo123
```

该说明仅用于备案审核期，不属于长期产品内容。

## 3. 具体改动文件

### 3.1 首页未登录跳转

文件：

```txt
frontend/app/page.js
```

改动位置：`fetchCurrentViewer()` 失败后的 `catch` 分支。

备案审核期临时逻辑：

```js
// 公安备案审核期临时配置：未登录首次打开站点时直接展示游客可见的曲目区。
router.replace('/tracks');
```

含义：

- 未登录用户访问 `/` 时不再直接进入登录页；
- 改为跳转到 `/tracks`；
- `/tracks` 本身是游客可见页面，可展示曲目区公开内容。

### 3.2 登录页底图审核说明

文件：

```txt
frontend/app/login/LoginForm.js
frontend/app/login/login.module.css
```

在登录页左侧底图区域增加：

```jsx
<div className={styles.auditNote}>
  <strong>备案审核说明</strong>
  <p>本站仅供吉他爱好者整理学习笔记与课程资料，无广告，不开放公共注册，无支付功能。</p>
  <p>审核测试账号：13382800426<br />审核测试密码：demo123</p>
</div>
```

并在 `login.module.css` 中新增 `.auditNote` 相关样式，使说明显示在登录页底图上。

## 4. 审核完成后的恢复方式

审核结束后，需要删除这些临时内容。

### 4.1 恢复首页未登录跳转

打开：

```txt
frontend/app/page.js
```

将：

```js
// 公安备案审核期临时配置：未登录首次打开站点时直接展示游客可见的曲目区。
router.replace('/tracks');
```

恢复为：

```js
router.replace('/login');
```

### 4.2 删除登录页审核说明 DOM

打开：

```txt
frontend/app/login/LoginForm.js
```

将：

```jsx
<div className={`${styles.image} ${styles.rise}`}>
  <div className={styles.auditNote}>
    <strong>备案审核说明</strong>
    <p>本站仅供吉他爱好者整理学习笔记与课程资料，无广告，不开放公共注册，无支付功能。</p>
    <p>审核测试账号：13382800426<br />审核测试密码：demo123</p>
  </div>
</div>
```

恢复为：

```jsx
<div className={`${styles.image} ${styles.rise}`}></div>
```

### 4.3 删除登录页审核说明样式

打开：

```txt
frontend/app/login/login.module.css
```

删除以下样式块：

```css
.auditNote { ... }
.auditNote strong { ... }
.auditNote p { ... }
.auditNote p + p { ... }
```

## 5. 恢复后的验证方式

恢复并重新构建后，应验证：

```bash
cd /root/player

docker compose -p video_player \
  -f docker-compose.yml \
  -f docker-compose.local.yml \
  build frontend

docker compose -p video_player \
  -f docker-compose.yml \
  -f docker-compose.local.yml \
  up -d --force-recreate frontend
```

浏览器验证：

1. 未登录访问 `/`，应回到正常登录流程或正式产品入口策略。
2. 访问 `/login`，不应再看到审核测试账号和备案审核说明。
3. 游客仍可通过既有游客入口访问公开曲目区。

## 6. 注意事项

- 审核测试账号和密码不应长期展示在页面上。
- 审核结束后务必删除登录页上的账号密码备注。
- 若测试账号后续不再需要，应在后台停用或修改密码。
- 本文档记录的是临时策略，不应作为长期产品需求。
