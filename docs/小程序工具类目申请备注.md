# 小程序「工具」类目申请备注（个人主体）

> 使用场景：微信公众平台 → 小程序 → 服务类目 → 申请「工具」类目时的"备注（必填）"栏，要求 20–200 字。
> 填写口径：与 ICP 备案保持一致——独立老师的学习记录辅助工具、不开放注册、无交易无广告；避免任何会被误判为"在线教育培训"的表述。

---

## 推荐版本（约 155 字，直接复制粘贴）

本小程序为个人开发的学习记录辅助工具，服务于本人线下吉他教学的少量学员。主要功能：学员使用管理员开设的账号登录，查看管理员推送的学习视频与练习作业，下载学习资料（音频、图片、文档），查看个人学习历史。不提供开放注册、在线授课、付费交易、广告及社交功能，内容仅由管理员上传维护，属信息记录与展示类工具服务。

## 备用精简版（约 80 字）

个人开发的学习记录工具，供本人线下吉他教学的学员登录查看学习视频、作业与历史记录，可下载学习资料。不提供注册、交易、广告及社交功能，内容由管理员统一上传维护。

---

## 填写与过审提示

1. **口径一致**：类目备注、小程序简介、版本提审的功能说明、ICP 备案信息，四处都按"学习记录查看工具"描述，不要互相矛盾。
2. **高危词规避**：不要出现"在线教育 / 网课 / 培训课程 / 报名 / 购课 / 付费会员"等字样，防止被要求提供教育类资质（个人主体无法提供）。
3. **名称风险**：小程序名含"教室"二字，若类目审核被驳回，可在备注末尾补一句"仅为已有线下学员提供资料查看，不开展在线培训业务"。
4. **登录表述**：写"管理员开设的账号登录"而不是"用户注册登录"——前者是工具的权限管理，后者可能触发社交/社区类审查。
5. **若被驳回**：按驳回意见调整表述后重新提交；必要时在版本提审时附上首页、课程页、资料页截图佐证"仅内容查看与下载"。
